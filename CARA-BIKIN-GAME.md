# Tutorial Membuat Game — untuk Kevin

Situs Kevin: kevingames.sinteniki.com

## Cara Bikin Game Baru

1. Buka Antigravity, pilih folder kevin-games.
2. Klik + New Conversation (percakapan baru).
3. Salin prompt sakti di bawah ini, ganti tulisan di dalam [kurung] dengan idemu.
4. Tunggu sampai selesai. Robot akan membuat gamenya dan mengirimnya ke GitHub sendiri.
5. Bilang ke Papa: "Sudah push, Pa!" Nanti Papa teruskan ke Ijah supaya game-nya tampil di internet.

Prompt sakti game baru:

Buatkan aku game baru.
Nama gamenya: [TULIS NAMA GAME]
Gamenya tentang: [TULIS IDEMU, misalnya: mobil balapan yang harus menghindari rintangan dan mengumpulkan bintang]
Buat gamenya di folder baru di proyek kevin-games ini, tambahkan kartunya di halaman utama, lalu commit dan push ke GitHub seperti biasa.

## Cara Mengubah Game yang Sudah Ada

1. Buka Antigravity, pilih folder kevin-games, klik + New Conversation.
2. Salin prompt ini dan ganti tulisan di dalam [kurung].
3. Tunggu selesai, lalu bilang ke Papa: "Sudah push, Pa!"

Prompt mengubah game:

Aku mau mengubah game [NAMA GAME, misalnya: catur].
Yang diubah: [TULIS KEINGINANMU, misalnya: tambahkan level yang lebih sulit dan suara tepuk tangan kalau menang]
Kerjakan di folder game itu, lalu commit dan push ke GitHub seperti biasa.

## Kalau Game-nya Rusak

Game [NAMA GAME] rusak. Yang terjadi: [CERITAKAN, misalnya: papannya tidak muncul, layarnya putih].
Tolong perbaiki sampai bisa dimainkan lagi, lalu commit dan push ke GitHub seperti biasa.

## Tips

1. Tulis idemu dengan kata-katamu sendiri. Tidak perlu kata-kata sulit, robotnya pintar.
2. Kalau robot bertanya, jawab saja dengan jujur dan sederhana.
3. Ubah satu hal dulu, lihat hasilnya, baru ubah yang lain. Seperti menyusun Lego satu per satu.
4. Setiap selesai, selalu akhiri dengan kata ajaib: commit dan push ke GitHub. Tanpa itu, game barumu tidak akan sampai ke internet.
5. Standar game Kevin: Setiap game memiliki tombol kembali ke halaman utama (`🎮 Kevin Games`) dan proteksi otomatis agar game tidak tertutup/hilang saat tombol kembali browser terpencet saat bermain.
